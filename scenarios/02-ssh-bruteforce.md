# Scenario 02 - SSH Brute-Force Detection

## Objective

Simulate repeated failed SSH authentication attempts and verify that Wazuh correlates multiple authentication failures into a high-severity brute-force alert.

## Test Environment

- Endpoint: Ubuntu 24.04 LTS
- SSH server: OpenSSH
- Log source: systemd / journald
- Wazuh Agent: 4.14.8
- Test account: `fakeuser`
- Source IP: `127.0.0.1` (localhost lab simulation)

## Attack Simulation

Several SSH authentication attempts were performed against the local SSH server using a non-existent user:

```bash
ssh fakeuser@localhost
```

Multiple incorrect passwords were intentionally entered to generate repeated authentication failures.

## Initial Detection

Individual failed login attempts generated Wazuh alerts including:

- Rule `5710` - Attempt to login using a non-existent user
- Rule `5503` - PAM user login failed

These alerts represent individual authentication failures.

## Event Correlation

Wazuh then correlated repeated Rule `5710` events using its native Rule `5712`:

```xml
<rule id="5712" level="10" frequency="8" timeframe="120" ignore="60">
  <if_matched_sid>5710</if_matched_sid>
  <same_source_ip />
  <description>sshd: brute force trying to get access to the system. Non existent user.</description>
  <mitre>
    <id>T1110</id>
  </mitre>
</rule>
```

The correlation logic requires 8 matching events from the same source IP within 120 seconds.

## Result

The simulated authentication attempts successfully triggered:

- Rule ID: `5712`
- Severity: Level 10
- Source IP: `127.0.0.1`
- Source user: `fakeuser`
- Decoder: `sshd`
- MITRE ATT&CK: `T1110 - Brute Force`
- Tactic: `Credential Access`

## SOC Analysis

This scenario demonstrates the difference between an isolated authentication event and a correlated security alert.

A single failed SSH login does not necessarily indicate an attack. However, repeated failures from the same source within a short period can represent brute-force behavior.

In this controlled laboratory, the alert is classified as a true positive generated by authorized testing activity.
